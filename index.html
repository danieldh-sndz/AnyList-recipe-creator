Getting the file into AnyList

  1. Paste your recipe here and tap Read recipe.
  2. Check the fields, then tap Save to library.
  3. On the Library tab, tap Export to save a .paprikarecipes file to Files.
  4. Open AnyList's Recipe Import page in Safari, sign in, choose the file you just saved, and tap Import Recipes. The steps are on AnyList's help page.

AnyList reads the Paprika recipe format, so that is what this app writes. Everything happens on your phone — no recipe text is ever uploaded anywhere.
